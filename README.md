# Calculator

A Python Tkinter-based Calculator application featuring a graphical user interface (GUI) with Light & Dark mode toggle, interactive calculation screen, and calculation history logging. The project demonstrates GUI app development, event handling, and calculation history management.

## Features
- Interactive graphical user interface (GUI) built with Tkinter
- Seamless Light Mode and Dark Mode theme toggling
- Live calculation history display built into the application window
- Automatic saving of calculation history
- Standard arithmetic operations including addition, subtraction, multiplication, division, and percentages

## Technologies Used
- Python (Core Programming Language)
- Tkinter (Graphical User Interface Library)
- JSON (Data Storage Format)
- File I/O (Reading and Writing Calculation History )

## What I Learned
- Building interactive desktop applications using Python and Tkinter
- Designing responsive UI components and managing color theme changes dynamically
- Implementing event handlers for custom button actions and calculator logic
- Reading from and writing calculation history data to files
